# Восстановление и вывод одновременно

Контрольный путь сначала восстанавливает все коэффициенты CRT одним
ядром, затем передаёт результат. Эксперимент FHERMA_CRT_PIPELINE=4
восстанавливает четыре непересекающихся диапазона. Передача первого
диапазона может идти одновременно с вычислением следующего.

Для этого обратный Harvey NTT записывает естественный порядок, используя
дополнительную shared-memory перестановку в tail. Иначе последовательные
блоки CRT соответствуют разрозненным диапазонам конечного результата.
CRT получает явное начало диапазона, при этом n остаётся полным размером
для таблиц и stride остатков. Эмуляция выполняет все четыре запуска.

В графе вычислительная ветвь записывает внутреннее событие после каждого
CRT. Ветка DMA ждёт соответствующее событие, затем выполняет два D2H и
записывает внешние output_ready. CPU читает только завершённые части.
После последнего D2H внутренняя зависимость возвращает ветку в исходный
stream до окончания capture. Буферы частей не перекрываются; все копии,
ожидания и создание возвращаемого vector остаются в run.

Потенциальная цена — дополнительные запуски CRT и меньшая загрузка GPU
в каждом запуске. Поэтому наличие перекрытия не гарантирует ускорения.
FHERMA_CRT_PIPELINE=0 оставляет один CRT и позволяет отдельно проверить
стоимость естественного порядка inverse.

Перед GPU выполнены 27 точных проверок: по девять на N32768 с обычным
и предельным модулем, ещё девять на fallback N1024. Все прошли.

Соглашения CUDA capture проверены по документации NVIDIA:
https://docs.nvidia.com/cuda/cuda-programming-guide/04-special-topics/cuda-graphs.html#cross-stream-dependencies-and-events
