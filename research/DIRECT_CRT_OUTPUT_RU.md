# Прямой CRT output с уведомлениями

Эксперимент FHERMA_CRT_OUTPUT_SIGNAL требует natural inverse, N32768,
восемь частей вывода и mapped completion flags. При отсутствии поддержки
flags или на меньшем N используется прежний D2H/event путь.

Буфер результата pinned и mapped, GPU-адрес получен явно через
cudaHostGetDevicePointer. Каждая CRT-плитка записывает 32 последовательных
коэффициента coalesced stores. Все 128 потоков вызывают __threadfence_system,
затем __syncthreads; только после этого поток 0 увеличивает GPU-счётчик
готовых плиток своей части. Последний из 128 блоков публикует aligned
volatile uint32 flag=1 в mapped памяти, затем system fence. CPU использует
acquire load и копирует готовую часть в свежий обычный std::vector.

Счётчики сбрасываются cudaMemsetAsync узлом графа перед вычислениями
каждого run. CPU сбрасывает flags перед replay, после наблюдения всех
flags предыдущего run. Запись результатов и все CPU-копирования входят
в run. Счётчики/flags содержат только синхронизационные метаданные;
не сохраняются входы или готовые ответы. CPU не выполняет RMW над GPU
атомиками. Медленный путь ожидания синхронизирует stream и сообщает
ошибку CUDA либо отсутствующий flag. На исключении также ждём stream.

Системный fence каждого writer необходим: fence только потока 0 не
упорядочивает записи остальных потоков. Atomic counter расположен на GPU;
хост не опрашивает его. Natural inverse гарантирует соответствие плиток
неперекрывающимся непрерывным частям выходного массива.

Источник модели памяти: CUDA C++ Programming Guide 12.8, Memory Fence
Functions / Synchronization Functions:
https://docs.nvidia.com/cuda/archive/12.8.0/cuda-c-programming-guide/index.html

GMP-эмуляция проверяет индексацию и прямую запись в host output, но не
системную видимость GPU stores. Для неё обязателен реальный GPU прогон,
включая последовательные вызовы на одном состоянии. Победа по скорости
заранее не предполагается: system fences сами могут оказаться дорогими.

Первый GPU вариант ec6017f: 3/3 (+2/2 прогрева), 411,962 мкс;
CUDA CI прошёл. Он медленнее обычного D2H, оставлен экспериментом.
Следующая проверка FHERMA_CRT_VECTOR_OUTPUT записывает четыре 32-битных
слова за инструкцию lane. Начало плитки кратно 16 байтам, ABI stride 28
делится на 4; uint4 не пересекает границу плитки. Natural inverse обязателен.
CPU-адаптер выполняет те же индексы четырьмя скалярными stores.
