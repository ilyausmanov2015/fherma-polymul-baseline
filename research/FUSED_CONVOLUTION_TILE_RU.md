# Прямые NTT, произведение и обратный NTT внутри одной плитки

FHERMA_FUSED_TILE объединяет десять младших стадий Harvey-преобразований
на плитках по 1024 значения. Внешние пять прямых стадий остаются отдельным
ядром; после них каждый channel/tile независим для локальных преобразований.
Блок загружает A и B, выполняет два forward с общими twiddles, перемножает
остатки и выполняет inverse. В global memory записывается только inverse
результат, затем прежний inverse tail и точный CRT.

В двух shared tiles по 1024 uint32 (8 КиБ) хранятся входы. Для radix-8
каждый из 128 потоков держит восемь промежуточных произведений в регистрах.
После окончания всех forward reads блок синхронизируется, перезаписывает
первую shared tile в inverse-раскладке и снова синхронизируется. Это не
позволяет последним forward reads столкнуться с inverse stores при смене
перестановки shared memory. Внутри каждой стадии thread-группы непересекаются.

Убираются запись двух спектров и их повторное чтение: 4*64*32768*4 байт,
то есть 32 МиБ global traffic. Корни, Shoup/lazy арифметика, нормализация
и CRT не меняются. Канонический режим 31-битных простых сохраняется.
На N!=32768 используется прежний путь. Параметры ввода и вывода взяты
из подтверждённого a32b5aa; новые эксперименты графа/CRT output отключены.

Меньше обращений к памяти не гарантирует ускорения: совместная обработка
A/B повышает число живых регистров. Перед продвижением нужны независимый
GMP, CUDA-сборка с resource report и реальное измерение GPU.
