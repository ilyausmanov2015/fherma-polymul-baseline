# Граф, ожидающий публикации входных сегментов CPU

FHERMA_INPUT_GRAPH переносит в один CUDA Graph H2D четырёх входных частей,
их подготовку, NTT/CRT, D2H и уведомления CPU. В начале run сбрасываются
только флаги готовности и запускается граф. CPU persistent input job копирует
свои данные в отдельные pinned сегменты; после acquire-подтверждений всех
workers основной поток публикует флаг части release-store. SFENCE после
streaming stores рабочих потоков предшествует их подтверждению.

Transfer stream в графе ждёт cuStreamWaitValue32(EQ,1), копирует готовую
часть и записывает внутренний event. Compute stream ждёт event и готовит
RNS, перекрывая эту подготовку с очередным H2D. Корневой event присоединяет
ветку transfer к capture; ожидание последнего input event присоединяет её
завершение к основному stream. Все GPU-зависимости выражены CUDA events;
флаги выражают только готовность данных, произведённых независимым CPU.

CUDA graph не получает адресов входных std::vector: он читает только
принадлежащие решению pinned buffers. Вся упаковка и публикация выполняются
внутри run. init создаёт пустые флаги, проверяет уже удовлетворённое ожидание
и захват, без вычислений над входами. При отсутствии поддержки остаётся
обычный путь enqueue. Для N!=32768 также остаётся обычный путь.

Критичный случай: исключение CPU после запуска графа не должно оставлять
GPU навечно ожидающим флаг. Поэтому catch сначала открывает все входные
флаги, затем синхронизирует оба stream. Граф может дочитать частично
подготовленные собственные буферы, но результат этого вызова не возвращается.
Пул копирования завершает собственные задачи до выхода из input_pipeline.
Новый вызов сбрасывает флаги только после полного предыдущего результата.

Локальные тесты проверяют CPU-протокол и fallback; реальная поддержка
stream memory operations, захвата двух stream и порядок DMA проверяются
отдельным GPU benchmark. CPU-эмуляция не является проверкой CUDA Graph.

Семантика операций: NVIDIA CUDA 12.8 Driver API,
https://docs.nvidia.com/cuda/archive/12.8.0/cuda-driver-api/group__CUDA__MEMOP.html
