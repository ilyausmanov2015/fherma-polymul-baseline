# Одна задача CPU на весь вывод

FHERMA_OUTPUT_WORKER_PIPELINE запускает выходную команду один раз на все
DMA-части. После ожидания очередного CUDA event/флага основной CPU публикует
ready=part+1 release-store и копирует свою долю. Рабочие потоки ждут ready
с acquire-load и последовательно копируют свои доли каждой готовой части.
Окончательное подтверждение всей работы выполняется один раз на поток.

Разбиение по 32-битным словам совпадает с CUDA D2H даже для маленьких N,
нечётного числа слов и пустых частей. Каждая часть копируется только после
публикации её готовности. Главный поток не использует пул для других задач,
пока все части не завершены. Если ожидание GPU бросает исключение, cancellation
освобождает ожидающие потоки; join завершается до уничтожения выходного вектора.
Уже опубликованные части могут докопироваться, неопубликованные не читаются.

tests/output_pipeline.cpp проверяет 20 комбинаций размера/числа частей,
145 точек отказа производителя, неприкосновенность будущих частей, guards
и повторное использование того же пула. Проверены CV, spin, selective wake
и полный input worker team. ThreadSanitizer пройден. Обычные 1050 задач
copy/prefault после изменения также проходят.
