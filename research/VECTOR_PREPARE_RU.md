# Загрузка AoS-входа по 128 бит

FHERMA_PREPARE_VECTOR читает четыре соседних 32-битных слова одним uint4
перед записью в shared tile с шагом 29. Арифметика подготовки и число
считанных байтов прежние. Цель — проверить, влияет ли ширина инструкции
на пропускную способность чтения mapped input через PCIe.

Выравнивание: cudaMalloc/cudaHostAlloc дают выровненную базу; коэффициент
занимает 28 слов = 112 байт, начало каждого коэффициента кратно 16.
Внутри коэффициента word кратно 4, 28 делится на 4. Вектор не пересекает
границу коэффициента; guard base+row<end предотвращает выход за последнюю
неполную плитку. Packed-смещения также кратны 112 байтам.

Локальный GMP-адаптер читает те же четыре индекса отдельными скалярами.
CUDA-путь с uint4 и его производительность проверяются отдельно на GPU.
Контрольный scalar путь сохранён под FHERMA_PREPARE_VECTOR=0.
