# Кандидат: четыре 217-битные компоненты и 16 простых

Это план следующего backend; GPU-ускорение пока не измерено.

Пусть B=2^217, q=B^4-c. Представляем каждый коэффициент как
A(Y)=a0+a1*Y+a2*Y^2+a3*Y^3, 0<=aj<B. Считаем произведение полиномов
по X в кольце Z[X,Y]/(X^N+1,Y^4-c). После этого подстановка Y=B
и редукция по q даёт исходную задачу точно.

Четыре целые компоненты результата Rj ограничены по модулю:

    |R0| <= N*(B-1)^2*(1+3*c)
    |R1| <= N*(B-1)^2*(2+2*c)
    |R2| <= N*(B-1)^2*(3+c)
    |R3| <= N*(B-1)^2*4.

Для c<2^28 максимум меньше 2^479. Шестнадцать 31-битных простых дают
произведение P около 2^496: setup обязан точно проверить P>4*max_bound.
Каждый p=1 mod 2N дополнительно выбирается так, чтобы c было четвёртой
степенью: c^((p-1)/4)=1. Два Tonelli–Shanks дают r с r^4=c. Корень
i=psi^(N/2) удовлетворяет i^2=-1. Тогда Y^4-c раскладывается на четыре
различных корня r, r*i, -r, -r*i.

Входы переводятся в четыре значения A(r*i^k) по каждому из 16 простых.
Требуются 64 малых NTT на полином против текущих 57, но исходный 868-битный
коэффициент редуцируется всего по 16 разным модулям. Таблицы NTT общие
для четырёх компонент, что уменьшает их объём в несколько раз.

После обратного NTT обратная 4-точечная DFT восстанавливает остатки Rj:

    u=f0+f2, v=f0-f2, s=f1+f3, t=i*(f1-f3)
    R0=(u+s)/4
    R1=(v-t)/(4*r)
    R2=(u-s)/(4*r^2)
    R3=(v+t)/(4*r^3).

Факторы 1/(4*r^j), N^-1, psi^-index и inverse(P/p mod p) объединяются
в постоянных Shoup-таблицах для CRT. CRT здесь может восстанавливать
полный знаковый integer Rj: сумма 16 взвешенных баз меньше 16P<2^500,
поэтому достаточно cuPQC BigInt512. Округление fixed-point alpha точно
по прежнему доказательству P>4*bound; знак и модуль берутся сравнением
S с alpha*P. Это позволяет уменьшить ширину CRT с 928 до 512 бит.

Результат — sum_j Rj*B^j mod q. Для каждого модуля Rj его сдвиг на 217*j
бит разбивается на low868 и high; low+high*c помещается в BigInt896 и
после одной условной редукции даёт величину по q. Знак учитывается через
q-value, затем четыре компоненты складываются cuPQC add_mod.

Проверки перед GPU: независимые точные convolution/oracle; корни r и i;
все bounds и CRT; извлечение компонент на границах 217/434/651 бит;
случаи нуля, q-1, знака негациклической свёртки, случайных полиномов.
Потенциальный выигрыш: меньше работы при переводе входа и более узкая CRT.
Потенциальная потеря: на 12% больше NTT-каналов и дополнительная 4-точечная DFT.
