# Журнал оптимизации

Измерения FHERMA на RTX PRO 6000 Blackwell, N=32768, W=868.
Локальные CPU-проверки сравнивают результат с независимым GMP-эталоном;
их время не используется для оценки GPU-производительности.

окончательные конкурсные версии будут измеряться без диагностики.

## Профиль SoA

На трёх измеряемых случаях H2D занимает 615–657 мкс, D2H с возвратом
выходного вектора 617–624 мкс. Два прямых NTT — около 205 мкс,
обратный — около 131 мкс. Основной оставшийся расход приходится на
обмен с обычной pageable-памятью, поэтому следующий приоритет — pinned staging.

CUDA-сборка исходной специальной редукции: stage 160 регистров, spill 0.
Montgomery: stage 125 регистров, spill 0. Прямая редукция по словам:
stage 144 регистров, spill 0. Сборки выполнялись для sm_120 на CUDA 12.8.

## Порядок экспериментов

1. Заменить деление в mul_mod на точную редукцию для специального модуля.
2. Сравнить с Montgomery и устранить повторные проверки постоянного q.
3. Измерить стадии и передачи отдельно; проверить регистры и spill в сборке.
4. Попробовать размещение коэффициентов по словам и объединение стадий NTT.
5. Если широкая арифметика ограничит результат, перейти к малым NTT и CRT.

## Доказательство редукции

Пусть B=2^868, q=B-c, 0<c<2^28, 0<=a,b<q, z=a*b.
Первый шаг: t=(z mod B)+c*floor(z/B), t < (c+1)B <= 2^896.
Второй: r=(t mod B)+c*floor(t/B), r < B+c^2 < 2q.
Следовательно, два сворачивания и не более одного вычитания q дают
канонический остаток. Умножение сохраняет все 1792 бита cuPQC mul_wide.
Для основной точки c=11993087. Параметр q приходит от платформы;
вариант ee46230 проверяет форму и имеет общий fallback. В вариантах
с прямыми операциями по словам проверка выполняется один раз в init;
неподдерживаемая форма q отклоняется явно.
